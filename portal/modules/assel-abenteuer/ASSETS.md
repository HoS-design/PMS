# Assets

This module uses a few small external PNG assets for obstacle visuals.

## Kenney Nature Kit

- Source: https://kenney.nl/assets/nature-kit
- License: Creative Commons CC0 1.0 Universal
- License URL: https://creativecommons.org/publicdomain/zero/1.0/
- Downloaded package: `kenney_nature-kit.zip`

Included files:

- `assets/kenney-wood-logs.png` from `Isometric/campfire_logs_NE.png`
- `assets/kenney-stones.png` from `Isometric/campfire_stones_NE.png`
- `assets/kenney-rock-block.png` from `Isometric/cliff_block_rock_NE.png`

The remaining textures and the Assel sprite are generated in `game.js` at runtime.
