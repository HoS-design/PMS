Merkhilfe Passiv

  • Aktiv: Der Handelnde ist Subjekt. („Der Hund beißt den Mann.“)
  • Vorgangspassiv: werden + Partizip II. („Der Mann wird gebissen.“)
  • Handelnder optional: von + Dativ („… von dem Hund“).
  • Zeitform bleibt gleich: Präsens → „wird …“, Präteritum → „wurde …“, Perfekt → „ist … worden“.
  • Das Akkusativ-Objekt wird im Passiv zum Subjekt.

Ziel: Du erkennst schnell, ob eine Passivform zeitlich und inhaltlich passt.
